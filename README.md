
# Credit-Wise Loan Analysis

## Project Overview
This project focuses on analyzing loan application data to understand borrower profiles, loan approval patterns, repayment behavior, and credit risk.

The objective is to explore financial data and generate meaningful business insights that can help financial institutions make better lending decisions.

## Project Objectives
- Analyze loan application data.
- Understand borrower demographics and financial profiles.
- Explore loan approval and rejection patterns.
- Identify factors associated with loan repayment.
- Analyze loan status and credit risk.
- Generate business insights and recommendations.

## Key Analysis
- Loan application distribution
- Borrower income analysis
- Loan amount analysis
- Credit history analysis
- Loan approval trends
- Loan status distribution
- Relationship between borrower characteristics and loan outcomes

## Business Questions
1. What is the distribution of loan applications?
2. How does applicant income affect loan approval?
3. What is the relationship between credit history and loan status?
4. Which borrower profiles have higher loan approval rates?
5. How do loan amounts vary across applicant groups?
6. What factors are associated with loan rejection?
